# 手办拆件、分色与过程留痕

目标是得到可编辑的分件模型、可复查的装配关系和切片项目，同时留下能够说明实际工作量的过程档案。沿真实斜面、凹槽、服饰接缝确定边界，用参考图和贴图确认部件身份与配色。

## 开始前

1. 查看用户给的设计图、原始贴图及现有模型的正面、背面和侧面。确认颜色来自材质、UV、顶点色还是切片软件涂色。留存带贴图版本，另建灰模工作副本。
2. 检查对象、连通块、单位、世界变换、整体尺寸、法线、孔洞和非流形边。先保存原始工程副本，不覆盖唯一原件。修改或修复前后都留存可比较版本。
3. 从上下文读取打印机、喷嘴、材料、多色设备、成品大小和用户偏好。缺少时先做不依赖答案的检查。180 mm 可作为此类 Q 版手办的起始提案，并非所有模型的固定尺寸。
4. 检查可用 Blender MCP、Blender Python 和切片工具。优先用已连接工具；没有 MCP 时，可用独立 Blender 后台进程运行本地脚本，不把后台修改描述成当前 UI 已修改。保存 `.blend` 前核对输出路径。
5. 为本项目建立过程目录，按 [evidence.md](references/evidence.md) 逐步保存。毕业设计场景从第一步开始留痕，不等全部完成再补写。

## 拆件判断

- **颜色决定外观分组，几何决定切线。** 用户粗糙涂出的粉色鞋头只能辅助定位；应沿鞋头真实斜面、弧形边缘描线。另一只未涂色的鞋也检查自身几何，不能漏掉或直接照搬镜像坐标。
- 先划分结构大件，再处理必要的大色块。相近颜色可合在一个实体中；眼睛、花纹、袜上细藤条等小区域可留在母体做多色打印、贴花或手涂，保留其颜色身份。合并几何不等于全部涂成同一种色。
- 腰饰若由多道绳圈、结和垂带构成，优先做有背板或隐藏连接的一体装饰件。腿部优先把关节藏在短裤、袜口、靴口等自然位置，避免为每一圈藤条增加独立零件。
- 每个候选件写明保留/独立理由、接缝、装配方向、连接方式、颜色和风险；件数由可打印性、抓持能力、强度和实际装配决定。

具体切线、切刀及连接方法见 [splitting.md](references/splitting.md)。需要手动画边或讲解用户的插件时读 [seanixz.md](references/seanixz.md)，原 `.py` 在 `assets/blender/`。这个插件是可选操作工具，不能代替观察参考图和验证装配。

## 执行与验收

1. 先完成一个有代表性的试拆部件。保存带贴图定位图、灰模切线图、切刀、原位及分离预览、间隙参数和检查报告。按已有授权继续后续步骤；用户明确要求先看试件时先交付试件。
2. 确认切线后创建共享的成对界面。公榫、母槽使用同一个参数源，给出明确的单边余量、轴向余量及抽离方向。避免只在最终装配姿态无碰撞、实际却无法装入。
3. 每次布尔或修复后检查闭合性、正体积、连通块、薄壁、外观和贴图。`scripts/audit_parts.py` 可验证导出 STL 的几何和采样路径；它不能验证壁厚、连续路径或真实材料配合，必须补充人工检查及必要的小样。
4. 保留原始 UV 参考。布尔产生的新面没有天然正确的 UV；在保留外表面对应关系的基础上转移/重投影贴图，给内部切面明确材质。导出 STL 后不能假定 UV 仍存在。
5. 按 [bambu.md](references/bambu.md) 制作可编辑 3MF，确认机型、单位、方向、盘位、支撑、颜色映射及切片结果。启动实体打印属于单独的用户操作范围。
6. 在每次有意义的变更后归档记录和证据。新版本通过后仍保留试拆、失败与返工阶段，并注明原因。

## 交付

交付原位装配 `.blend`、独立零件、可编辑/已切片 3MF（完成到哪一步就说明哪一步）、分件与装配说明、配色表、预览、数值报告及过程档案索引。明确区分几何检查通过、切片通过和实体试装通过；没有试打不得写成已验证实物拼装。

工具发布或 Skill 更新时，仅收录通用代码和授权包含的插件。项目的模型、贴图和毕业设计过程文件保留在对应项目目录，除非用户明确要求一起发布。
