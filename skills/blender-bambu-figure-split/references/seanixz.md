# 随附 SeanIXz Pro 1.5.9

原文件在 `../assets/blender/seanixz_print_helper_pro_v1_5_9.py`。插件内 `bl_info` 声明 Blender `(5, 1, 0)`，面板为 `View3D > N 面板 > SeanIXz Pro`。这只是作者声明，不代表当前 Blender 的所有功能已经验证。

## 安装与验证

在 Blender 偏好设置的插件管理中使用“从磁盘安装 / Install from Disk”选择原 `.py` 并启用，具体入口取决于版本。回到 3D 视图按 N，检查 `SeanIXz Pro` 面板出现。对测试副本执行一次小切割并检查是否能撤销、预览和保存；仅 Python 语法编译通过不能证明插件运行正常。

Skill 的脚本和插件是独立工具。记录中准确写本步骤是否真正调用了 `seanixz_pro.*` 操作；仅把插件放入包内不算使用插件拆了模型。

## 与本工作流对应的按钮

以下名称来自随附版本的面板代码：

1. **01 单位 / 尺寸**，设置整体尺寸后用已知尺寸核对导出结果。不要仅因为界面显示 mm 就认定顶点数值已经正确换算。
2. **04 切刀 → 吸附 + 法向 + 起点**，生成单点并进入编辑模式。用 G 移动到实际斜面边缘，用 E 延伸轮廓。只选首尾两个端点后按“闭合”；选中闭合圈后“拟合”，原控制点保留，在相邻点间插入过渡点。
3. **05 卡榫 / 锁止**，用“卡榫1/卡榫2”、深度、反向和倒角等选项构造接口。插件的“外扩/比例”不直接等于所需毫米单边间隙，生成后必须测量真实尺寸。固定手办不必启用活动关节。
4. **08 布尔**，先选择切刀，再选择目标模型，最后活动对象必须是被切模型。先“实时实体预览”，确认后“实体执行”。“普通预览/普通执行”与实体化模式不同，按切刀是否已有封闭体积选择。
5. **09 收尾**，检查输出件。“流形化”或体素重构可能改变表面和 UV，只在发现实际问题并保留阶段副本后使用。不要为了跑流程而把精简、重建、清理全执行一遍。

“Global / 备份”注明仅在布尔切刀计算前备份，精简、重建、清理及切割结果不重复备份。毕业设计留痕必须自己另存阶段工程，不能依赖插件自动备份覆盖全部过程。

插件生成的预览展开位置用于观察，不是装配坐标或打印排盘。导出前恢复/确认原位，分别保留原位版和爆炸展示版。
