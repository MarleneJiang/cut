# 几何拆件与装配方法

## 先形成部件表

在项目记录中列出 `部件 ID / 参考图颜色 / 几何依据 / 是否独立 / 合并理由 / 接缝 / 抽离方向 / 连接方式 / 打印方向`。用同一 ID 命名对象、STL、3MF 和报告。不要把同色的互不相连区域自动当成一个可打印实体。

常见选择由实物尺寸决定：帽子与头部可沿帽檐藏缝；脸、头发可按可达边界分件或做同一件多色打印；眼白、虹膜、高光通常适合留在面部。衣服花纹和藤条可以保留颜色层而不拆成细小零件。背在身后的手若相连，可保留在躯干以减少无法插入的接头。腰饰若只拆正面，应记录背面仍采用涂色的取舍。

## 沿边描线

1. 用正交视角检查灰模和贴图，选定容易看清真实斜面/凹槽的局部视角。先识别可见边，补看侧面与背面，避免仅按二维投影切穿背后结构。
2. 以稀疏控制点沿真实边缘画闭合曲线。凹槽明显时，可在局部截面中用法线变化、曲率或深度斜率辅助找点，再核对实际表面。不要把噪点直接连成锯齿。
3. 轻度平滑或拟合，保留角点和轮廓端点。保存原始点、拟合点和灰模叠加图。拟合不能把切线推到可见正面、削掉颜色边框或改变主要轮廓。
4. 对称件采用相同判断方法；模型有姿态或形变差异时，各自重新描线。

## 生成有厚度的切刀

从已确认轮廓产生封闭切刀，并确保其穿透需要切开的实体。沿预定抽离方向建立开口界面，避免倒扣。相邻件共享同一个基准切面，余量在该基准上产生，不能分别猜两条相近曲线。

平直的隐藏面可以用平面。曲面可用图形高度场 `h(x, y)`，沿局部 +Z 延伸到外部，形成无折返的切刀。`scripts/heightfield.py` 提供 `graph_above(gx, gy, heights, ceiling)`；坐标轴必须由模型局部方向变换得到。它只处理单值高度场，不能覆盖回折、多层或任意拓扑边界。高度场范围必须覆盖需要切开的截面；外围侧壁不得在可见外表面留下额外伤口。

切割时分开计算 `source ∩ cutter` 与 `source − enlarged_cutter`，或相反方向的成对实体。验证剩余每块都封闭。源模型本身有缺陷时先记录，局部修复后比较外轮廓；整体体素重建可能丢失 UV、锐边和细节，不应作为每次切割的默认前置步骤。

## 接头和间隙

试件曾采用约 0.20 mm 可见边缝、0.23 mm 榫槽单边余量和约 3 mm 啮合深度。这些是曾用的试验参数，不是 A1 的保证精度。尺寸、方向、材料、象脚、支撑表面和喷嘴会改变实际配合，最终用同材料同方向的小样决定。

在宽厚区域使用带导角和防转形状的榫；小装饰件也可用定位柱加胶接。母槽沿装配方向留入口和底部余量，周围必须有足够壁厚。检查公榫实际连在零件上，母槽不贯穿可见表面。连接处宁可保留较厚的隐藏背板，也不要留下独立薄片或零体积接触。

## 数值检查

所有 STL 顶点以毫米表示，并保留装配坐标。不要传入排盘后的坐标。检查脚本合并 STL 中精确重复的顶点，仅恢复连接关系，不填孔、不自动修法线。报告有问题时修复模型后重跑。

写一个 JSON 清单，路径相对清单文件：

```json
{
  "units": "mm",
  "parts": {"boot": "boot.stl", "toe": "toe.stl"},
  "overlap_tolerance_mm3": 0.0001,
  "assembly_order": [
    {"moving": "toe", "against": ["boot"], "direction": [0, -1, 0], "distance_mm": 15, "samples": 61}
  ]
}
```

```sh
.venv/bin/python scripts/audit_parts.py project/parts.json --output project/geometry-report.json
```

`assembly_order` 描述从完整装配开始的**拆卸顺序**；其逆序是装配顺序。每步只检查仍在装配体中的零件，已经取走的件不再挡路。`against` 必须包含全部仍在场的其他件，避免漏检。`direction` 是抽出方向，脚本归一化向量。距离必须足够移出周围件的包围盒，否则失败。

每一步输出所有原位零件对的体积交集和路径采样交集。离散采样有可能跳过薄障碍物，步长要小于相关特征尺寸并结合侧视检查；复杂路径需另做连续碰撞检测。报告通过不代表壁厚、表面质量或材料公差已通过。
